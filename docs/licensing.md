# Licensing release gate

This repository does not yet grant an open-source license.  Do not create a
public release until the copyright owners and, where required by funding or
institutional policy, the relevant technology-transfer offices approve a
license.

Candidate licenses for approval are MIT and BSD-3-Clause.  The decision record
must identify:

1. every copyright owner of the Python and MATLAB code;
2. grants, contracts, or exceptional institutional resources that may affect
   ownership;
3. written approval of the selected license and copyright notice;
4. the commit that adds `LICENSE` and removes the pending-license warning.

This checklist records an unresolved external decision; it is not itself a
software license.
