# MATLAB agent-based model

This is the supported MATLAB reference implementation. `src/` uses the same
nondimensional configuration vocabulary and discrete update semantics as the
Python ABM. Original pre-refactor `.m` files are retained separately under
`legacy/matlab_abm/` and are not used by these paper entry points.

The implementation is self-contained: paper parameters are resolved through
`matlab_abm_config.m`, update rules live in `matlab_abm_simulate.m`, and the
numerical conventions shared with the Python ABM are documented in
`docs/agent-based-model.md`.

## Requirements

- MATLAB R2024b or a reasonably recent release;
- Statistics and Machine Learning Toolbox (`binornd`, `mnrnd`, and `poissrnd`).

No FEniCSx or Python installation is required for the MATLAB implementation.

## Running paper cases

From the repository root:

```matlab
addpath(genpath('matlab'));

% M3AS ABM cases 1, 2, or 3; creates the corresponding paper figure files.
result = reproduce_m3as(1);

% Police-response ABM cases that appear in the paper: 1, 2, 8, or 9.
result = reproduce_police_extension(8);
```

Full runs write under `runs/matlab/<case-name>/`:

- `result.mat`: selected field snapshots, integer populations, lightweight
  spatial averages, cumulative events, summary, and resolved configuration;
- `config.resolved.mat`: the exact input structure;
- `summary.json`: totals useful for automated checks;
- the numbered paper figure PNG generated by the example function.

`matlab_abm_config.m` is the only paper-parameter registry. The simulator does
not contain Case numbers, `Bbar`, or hidden plotting times. Scalar configuration
fields may be replaced by grid-sized arrays before calling
`matlab_abm_simulate`, so heterogeneous `A^st`, generation, and initial fields
remain supported.

## Programmatic use

```matlab
addpath(genpath('matlab'));
config = matlab_abm_config("police", 1);
config.initial.seed = 91;
result = matlab_abm_simulate(config);
```

The main arrays are `A`, `rho`, `pi`, `H`, `expected_S`, `realized_S`,
`criminal_counts`, and `police_counts`. Criminal and police populations remain
nonnegative integers; police movement conserves the exact agent budget.

## Tests

```matlab
addpath(genpath('matlab'));
results = runtests('matlab/tests');
assertSuccess(results);
```

The tests are intentionally small. Paper-scale cases are stochastic and long,
so regression should compare seeded summary statistics and spatial scales rather
than exact equality with the historical notebook images.

## Historical files

`legacy/matlab_abm/` contains `compare_system.m`, `system_evolve.m`, older
visualization helpers, and the original example scripts for provenance. New
work should call the top-level `matlab_abm_*` API. This implementation uses
nondimensional time directly, matching the YAML configuration convention.
